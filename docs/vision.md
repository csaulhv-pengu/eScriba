# eScriba – Vision

eScriba is a free and open-source writing tool inspired by the ancient scribes,
whose work was not only to write, but to preserve meaning and structure.

## Core Principles
- Offline first
- Plain text formats (Markdown, YAML)
- No lock-in
- Writer-focused, not distraction-focused
- Free software forever

eScriba is not a word processor.
It is a place to think, structure and write long-form texts.

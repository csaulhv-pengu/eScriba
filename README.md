# eScriba

**eScriba** is a free and open-source desktop writing tool designed for long-form writing:
novels, essays, academic texts and personal projects.

## Philosophy
- Offline first
- Human-centered design
- Plain text (Markdown)
- Open formats
- Free software forever

## Features (planned)
- Chapter and scene organization
- Character and location tracking
- Markdown editor
- Project-based structure
- Export to PDF and EPUB
